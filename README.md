# ⚡ mef-battery

Легковесный монитор заряда беспроводных периферийных устройств для Windows на языке **Rust**.  
Отображает реальный процент заряда и статус вашей мыши прямо в системном трее Windows без необходимости держать запущенным тяжелый софт.

---

### Особенности

* **Нативный Win32 System Tray**: иконка в трее рядом с часами с динамическим уровнем заряда (зеленый / желтый / красный / статус зарядки).
* **Минимальное потребление ресурсов**: **< 2 МБ RAM** и **0% CPU** в фоне.
* **Без зависимостей**: один автономный `.exe` файл без внешних DLL, Python или .NET рантаймов.
* **Поддержка Attack Shark R1**: прямое чтение телеметрии через USB/HID (2.4 GHz ресивер `1D57:FA60` и проводной режим).
* **Автоматическое переподключение**: корректно отслеживает засыпание мыши и повторное подключение донгла.

### Как собрать проект через GitHub Actions

Вам **не нужно** устанавливать Rust, Visual Studio или компиляторы на свой компьютер. Сборка полностью автоматизирована через облако GitHub:

1. Создайте новый репозиторий на [GitHub](https://github.com/new) с названием `mef-battery` (публичный или приватный).
2. Загрузите файлы этого проекта в репозиторий:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of mef-battery"
   git branch -M main
   git remote add origin https://github.com/<ваш_логин>/mef-battery.git
   git push -u origin main
   ```
   *(Или просто перетащите файлы через браузер в репозиторий).*
3. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
4. Вы увидите запущенный workflow **Build and Release mef-battery**.
5. Через 1–2 минуты сборка завершится — кликните по ней и скачайте готовый архив **`mef-battery-windows-x64.zip`** из раздела **Artifacts**!

### Автозагрузка при старте Windows

Чтобы `mef-battery.exe` запускался автоматически при включении ПК:
1. Нажмите `Win + R`.
2. Введите `shell:startup` и нажмите Enter.
3. Скопируйте туда `mef-battery.exe` (или создайте на него ярлык).
